# chp3-실습 과제

## 1. 데이터 요구 분석 명세서

### 1. 유저 관리
  - 게임 시스템에 접속하는 사용자의 계정 정보를 등록하고 관리해야 한다.
  - 고객의 회원 가입, 회원 탈퇴가 가능해야 한다.
  - 고객 정보를 조회할 수 있어야 한다.

### 2. 유저 캐릭터 관리
  - 유저가 게임 내에서 생성하고 플레이하는 캐릭터의 상태와 재화 정보를 관리해야 한다.
  - 캐릭터는 ID당 제한 없이 생성 가능하다.
  - 레벨과 골드를 저장할 수 있어야 한다
  - 사용자는 캐릭터를 삭제할 수 있어야 한다.
